# Demo sandbox

- URL: `https://last-light-expedition.sociobot.in/demo`
- Local URL: `http://127.0.0.1:4173/demo`
- Entry: choose **Try it with sample data** on the first screen, or open `/demo` directly.
- Sample: weather seed `MIST-042`, the signal lens relic, three resources set to 7, and all six authored camp decisions.
- Label: the page keeps **Demo — sample data, nothing is saved** visible during sample play.
- Reset: **Reset demo** replaces the in-memory state with a new `MIST-042` run.
- Exit: **Start for real** discards the sample and starts a new real run.
- Storage: demo state and demo settings live in JavaScript memory only. The demo does not read or write the `last-light:*` localStorage namespace.
